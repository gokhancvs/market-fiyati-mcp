# v1.0.9

Örnek yapılandırma ilk kurulumda şube keşfini açar. Uzun `Retry-After` yanıtları sunucuyu artık
yeniden başlatılana kadar kilitlemez. Beklenmeyen hatalar operatör için stderr'e kaydedilir.

## Değişenler

- **İlk kurulum:** README ve `examples/mcp-config.json`, `MARKET_FIYATI_ENABLE_EXPERIMENTAL=true` içerir.
  Ürün aramaları şube ID'si ister, yakın şube keşfi de deneysel erişim gerektirir. Kod varsayılanı `false`
  kalır; şube ID'lerinizi biliyorsanız bu satırı silebilirsiniz. `server.json` ayarı listeler.
- **Hata mesajı:** `EXPERIMENTAL_DISABLED`, açılacak ayarı ve sunucunun yeniden başlatılmasını söyler.
- **Retry-After:** İlk hata upstream süresini olduğu gibi bildirir; yerel bekleme en fazla 60 saniye tutulur.
- **Tanılama:** `INTERNAL_ERROR` yanıtı genel kalır. Hata ve stack stderr'e en çok 4.000 karakterlik tek
  JSON satırı olarak yazılır. İstemci günlüğünü paylaşmadan önce özel verileri temizleyin.
- **Paket içeriği:** Sürüm notları ve bakımcı belgeleri npm paketine girmez.

## Geçiş

Mevcut kurulumlar değişiklik gerektirmez. Şube keşfi için deneysel erişimi açmadıysanız ve şube ID'lerini
bilmiyorsanız `MARKET_FIYATI_ENABLE_EXPERIMENTAL=true` ekleyip sunucuyu yeniden başlatın.

## Doğrulama

Offline kontroller ve fake fetch testleri hata mesajını, bekleme sınırını, tek satırlık tanılamayı ve paket
içeriğini sınar. Bağımsız kurulum testi gerçek npm binary'sini ağ engeli altında doğrular. Yeni live API
veya masaüstü istemci kabulü iddia edilmez.
