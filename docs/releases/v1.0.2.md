# v1.0.2

npm yayını tamamlandıktan sonra şu komutla bağlanın:

```sh
npx -y market-fiyati-mcp@1.0.2
```

Node.js 22+ gerekir. Varsayılan mod `offline`'dır. Sunucu stdio üzerinden mesaj bekler, HTTP portu açmaz.
MCP istemci yapılandırması README'de anlatılır. **Bu belge npm yayınının gerçekleştiğini göstermez.**

## Değişiklikler

- README ve teknik belgeler daha anlaşılır Türkçeyle yeniden yazıldı; teknik terimler İngilizce bırakıldı.
- Kurulum, tool seçimi, API sözleşmesi ve doğrulama sınırları kısa adımlar ve tablolarla düzenlendi;
  belgeler arasındaki tekrarlar azaltıldı.
- Kararlı sürüm tag'i push edildiğinde offline kontrollerin ardından npm'e OIDC ile yayın, integrity
  doğrulaması ve GitHub Release oluşturma otomatik çalışır.
- Paket, lockfile, MCP sunucusu ve README bağlantı örneği `1.0.2` sürümüne güncellendi.

Tool sözleşmeleri ve fiyat hesaplama davranışı değişmedi.

## Doğrulama sınırı

`MARKET_FIYATI_MODE=offline npm run check` biçim, lint, tip kontrolü, derleme, sentetik testler ve
arşivden kurulan CLI ile offline MCP bağlantısını doğrular. Ağ engeli testler boyunca açık kalır.
Bu kontroller live API, gerçek fiyat veya stok ya da masaüstünde elle yapılmış kabul testi için kanıt değildir.
