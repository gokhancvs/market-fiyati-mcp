# v1.0.1

npm yayını tamamlandıktan sonra şu komutla bağlanın:

```sh
npx -y market-fiyati-mcp@1.0.1
```

Node.js 22+ gerekir. Varsayılan mod `offline`'dır. Sunucu stdio üzerinden mesaj bekler, HTTP portu açmaz.
MCP istemci yapılandırması README'de anlatılır. **Bu belge npm yayınının gerçekleştiğini göstermez.**

## Değişiklikler

- npm arşivi yalnızca runtime JavaScript dosyaları ve belgelerle sınırlandı; geliştirme ve test dosyaları
  çıkarıldı.
- Paketlemeden önce derleme ve arşivden kurulan CLI ile offline MCP testi eklendi.
- README, npm bağlantı örneği ve CHANGELOG hazırlandı.

## Doğrulama sınırı

Kontroller sentetiktir ve ağ erişimi engellenmiş ortamda çalışır. Bu kontroller live API, gerçek fiyat
veya stok ya da masaüstünde elle yapılmış kabul testi için kanıt değildir.
[Doğrulama](https://github.com/gokhancvs/market-fiyati-mcp/blob/v1.0.1/docs/verification.md) · [Live test ve izinler](https://github.com/gokhancvs/market-fiyati-mcp/blob/v1.0.1/docs/live-testing.md).
