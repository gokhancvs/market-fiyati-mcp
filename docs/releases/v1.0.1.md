# v1.0.1

**npm yayını tamamlandıktan sonra bağlayın:**

```sh
npx -y market-fiyati-mcp@1.0.1
```

Node.js 22+ gerekir. Varsayılan `offline`; stdio mesajı bekler, HTTP portu açmaz.
MCP istemci yapılandırması README'dedir. **Bu belge npm yayınının gerçekleştiğini göstermez.**

## Değişiklikler

- npm arşivi çalışma JavaScript'i ve belgelerle sınırlandı; geliştirme/test dosyaları çıkarıldı.
- Paketlemeden önce derleme ve arşivden CLI/offline MCP testi eklendi.
- README, npm bağlantı örneği ve CHANGELOG hazırlandı.
