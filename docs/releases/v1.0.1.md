# v1.0.1

Bu sürüm npm dağıtımı için hazırlanır. Bu belge npm yayınının gerçekleştiğini göstermez.

## Değişiklikler

- `market-fiyati-mcp` paketinin çalışma dosyaları ve belgelerle sınırlandırılmış npm dağıtımı.
- Paketlemeden önce otomatik derleme; geliştirme ve test dosyalarının arşivden çıkarılması.
- Arşivden CLI ve offline MCP çalıştırma testi.
- Üç adımlı README, açılır teknik ayrıntılar, npm bağlantı örneği ve CHANGELOG.

## Kullanım

npm yayını tamamlandıktan sonra `npx -y market-fiyati-mcp@1.0.1` ile çalıştırılır.
Node.js 22 veya üzeri gerekir. MCP istemci yapılandırması README'dedir.
Varsayılan mod offline'dır; terminalde stdio mesajlarını bekler, HTTP portu açmaz.

## Doğrulama sınırı

Kontroller sentetik ve ağ erişimi engellenmiş testlere dayanır. Bu paket hazırlığı
canlı API, gerçek fiyat/stok veya masaüstü istemcisinde manuel kabul doğrulaması değildir.
Kullanım izinleri ve bilinen sınırlar [doğrulama belgesinde](../verification.md) ve
[canlı test rehberinde](../live-testing.md) açıklanır.
