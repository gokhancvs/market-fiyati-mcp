# v1.0.5

Bu sürüm npm'de yayımlandı; MCP Registry yayını yapılmadı. Kurulum (bu sürümde varsayılan mod `offline`'dır):

```sh
npx -y market-fiyati-mcp@1.0.5
```

## Değişiklikler

- README npm ile kurulumu öne çıkarır; sabit sürümlü MCP örneği ve sekiz keşif anahtar kelimesi eklendi.
- npm paketine giren belgeler açık listeyle sınırlandı. Temiz bir kurulumda gerçek npm binary'sini
  sınayan kontrol, Ubuntu/Windows CI işleri ve yayın öncesi aynı arşivin kontrolü eklendi.
- Yayın doğrulaması sürüm, bütünlük ve `latest` etiketini kontrol eder. Geçici registry ve gövde okuma
  hataları sınırlı süreyle tekrar denenir; paket yeniden yayımlanmaz.
- Durum, sepet, ürün karşılaştırması ve fiyat geçmişi tool'larının çıktı alanları şemada tanımlandı.
  Eksik veriler için `null` ve upstream ek alanlar korunur; fiyat hesapları değişmedi.
- Güvenlik bildirim politikası, güvenlik güncellemeleri için Dependabot yapılandırması ve
  sonraki ayrı MCP Registry yayını için `server.json` / `mcpName` metadata'sı eklendi.

## Doğrulama kapsamı

Offline kontroller ağ engeliyle çalışır; bağımsız kurulum testi paketi yalnız üretim bağımlılıklarıyla
kurar. Sentetik testler live API davranışını veya gerçek masaüstü istemci kabulünü kanıtlamaz.
MCP Registry manifesti hazırlıktır; npm yayını otomatik katalog kaydı oluşturmaz.
