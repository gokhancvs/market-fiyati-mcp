# v1.0.11

Büyük tool yanıtları artık MCP SDK 1.30+ istemcilerinde bağlantıyı kapatmaz. Sürüm, MCP Registry'ye otomatik
yayımlanan ilk sürümdür.

## Değişenler

- **Büyük yanıtlar:** Tool sonucunun stdio mesajı (metin, `structuredContent`, escape ve protokol alanları)
  9 MiB ile sınırlandı. Daha önce 8 MiB'lik zarf sınırının altındaki bir yanıt 10 MiB'yi aşan bir mesaj
  üretebiliyordu. Artık sınırı aşan yanıt yerine `OUTPUT_TOO_LARGE` (`resource: messageBytes`) döner ve istek
  ölçümleri korunur. Zarfın pratik tavanı yaklaşık 4,5 MiB'dir; hata alırsanız `size` veya şube sayısını
  azaltın.
- **MCP Registry:** Sürüm tag'i `server.json`'ı resmî MCP Registry'ye `io.github.gokhancvs/market-fiyati-mcp`
  adıyla yayımlar. Yayın GitHub OIDC ile yapılır; `mcp-publisher` sabit sürüm ve SHA-256 ile doğrulanır.
- **CI:** Yayın workflow'u, `main` branch korumasının zaten zorunlu kıldığı tam platform matrisini tekrar
  çalıştırmaz. Tag commit'inde offline kontroller ve bağımsız kurulum testi çalışmaya devam eder.

## Geçiş

Mevcut kurulumlar değişiklik gerektirmez. İstemci yapılandırmasındaki sürüm pinini
`market-fiyati-mcp@1.0.11` yapıp sunucuyu yeniden başlatın.

## Doğrulama

Offline kontroller ve SDK istemcisiyle yapılan bellek içi testler mesaj sınırını, sınır değerini ve istek
ölçümlerinin korunmasını sınar. Bağımsız kurulum testi paket içeriğini doğrular. Registry yayını bu sürümün
tag çalışmasında ilk kez uzak ortamda çalışır. Yeni live API veya masaüstü istemci kabulü iddia edilmez.
