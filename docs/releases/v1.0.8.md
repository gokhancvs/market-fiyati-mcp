# v1.0.8

Paket artık mod belirtilmediğinde `live` çalışır. Normal fiyat sorgusu için önce offline test yapmak veya live testi ayrıca başlatmak gerekmez. CLI, MCP rehberi, Registry metadata ve kurulum
belgeleri bu akışla eşitlendi. Başlangıç, keşif ve status ağ isteği göndermez; HTTP veri sorgusuyla başlar.

## Geçiş

- **Geliştirme ve ağsız kullanım:** `MARKET_FIYATI_MODE=offline` açıkça ayarlanmalıdır. Önceden mod
  belirtmeyen kurulumlar 1.0.8'de live sorgu gönderebilir. Testlerin gerçek ağ engeli korunur.
- **Eski istemci ayarı:** Açık `offline` kendiliğinden kaldırılmaz. Normal kullanım için `live` yapın
  veya 1.0.8'e yükselttikten sonra değişkeni kaldırın; sunucuyu yeniden başlatın.
- **Şube keşfi:** Deneysel erişim varsayılanı hâlâ `false`. Şube ID'leri bilinmiyorsa ilk kurulumda
  `MARKET_FIYATI_ENABLE_EXPERIMENTAL=true` ayarlayın. Konum, yarıçap ve şube seçimi kuralları değişmedi.

## Doğrulama

Offline kontroller ve fake fetch testleri varsayılan live davranışını, açık offline engelini ve ayrı
deneysel kilidi sınar. Bağımsız kurulum testi gerçek npm binary'sini varsayılan live ve açık offline
ayarlarıyla, iki süreçte de gerçek ağ engeli altında doğrular. Yeni live API veya masaüstü istemci
kabulü iddia edilmez.
