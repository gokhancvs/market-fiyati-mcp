# v1.0.4

npm yayını tamamlandıktan sonra Node.js 22+ ile bağlanın:

```sh
npx -y market-fiyati-mcp@1.0.4
```

Varsayılan mod `offline`'dır. MCP istemci yapılandırması README'de anlatılır.

## Değişiklikler

- npm'in kabul ettiği paketin registry'de görünmesi için toplam bekleme 25 saniyeden beş dakikaya
  çıkarıldı: en fazla 60 kez, beşer saniye beklenir. HTTP istek süreleri buna eklenir.
- Gecikmeli görünürlük ve sınır sonunda durma sentetik testlerle doğrulanır. Paket bir kez gönderilir;
  sürüm ve integrity doğrulanmadan yayın başarılı sayılmaz.
- Paket, lockfile, MCP sunucusu, README ve yayın örnekleri `1.0.4` sürümüne güncellendi.

Tool sözleşmeleri ve fiyat hesaplama davranışı değişmedi.

## Doğrulama sınırı

`MARKET_FIYATI_MODE=offline npm run check` biçim, lint, tip kontrolü, derleme ve sentetik testleri kapsar.
Paket testi arşivden kurulan CLI'ı ve offline MCP bağlantısını doğrular. Bu kontroller live API, gerçek
fiyat veya stok için kanıt değildir. npm yayınının sonucu ayrıca registry ve GitHub Actions üzerinden doğrulanır.

[Doğrulama](https://github.com/gokhancvs/market-fiyati-mcp/blob/v1.0.4/docs/verification.md) · [Live test ve izinler](https://github.com/gokhancvs/market-fiyati-mcp/blob/v1.0.4/docs/live-testing.md).
