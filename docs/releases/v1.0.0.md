# v1.0.0

**Kaynak arşivini açın; Node.js 22+ ile kurun:**

```sh
npm ci --ignore-scripts
npm run build
npm run check
```

MCP bağlantısı: arşivdeki `README.md` ve `examples/mcp-config.json`.
Bu ilk sürüm hazır ikili veya npm paketi yayımlamaz; `private: true` npm yayımını engeller.

## İçerik

- Ürün arama, şube fiyatı, geçmiş ve sepet için **15 araç, 3 kaynak, 3 istem**.
- Her çağrıda açık konum/şube, API facet filtreleri ve sınırlı sayfalama.
- TRY/kuruş hesabı; eksik sepette `total=null`.
- Kaynak uyarıları, istek ölçümleri, şube kapsamı; iptal/timeout/bütçe/kaynak sınırları.
- Ağ engelli sentetik testler ve istemciden bağımsız kabul kiti.

## Doğrulama sınırı

Hazırlık otomasyonu Ubuntu 24.04 Node 22/24, macOS Node 24 ve üretim bağımlılığı denetimi çalıştırır.
Sentetik başarı gerçek fiyat, stok, kampanya, uzak API veya masaüstü manuel kabul kanıtı değildir.
Bu sürüm hazırlığında canlı API testi yapılmaz.

Varsayılan `offline`; deneysel uçlar kapalı. Canlı erişim operatör kararı ve API izni gerektirir.
Pazar/şube kapsamı tamlık garantisi vermez; deneysel market listesi HTTP 500 dönebilir.
[Doğrulama](../verification.md) · [Canlı test](../live-testing.md).
