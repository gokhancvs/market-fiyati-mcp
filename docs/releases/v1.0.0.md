# v1.0.0

Market Fiyatı MCP'nin ilk sürümü: ürün arama, şube fiyatları, fiyat geçmişi ve
sepet karşılaştırması için TypeScript stdio MCP sunucusu.

## İçerik

- 15 araç, 3 kaynak ve 3 istem şablonu.
- Açık konum/şube bağlamı, API facet filtreleri ve sınırlı sayfalama.
- TRY/kuruş bazında ürün ve sepet karşılaştırması; eksik sepette `total=null`.
- Kaynak uyarılarının korunması, istek ölçümleri ve şube kapsamı bilgisi.
- İptal, zaman aşımı, istek bütçesi ve kaynak kullanım sınırları.
- İstemciden bağımsız sentetik kabul kiti ve ağ erişimini engelleyen testler.

## Kurulum

Node.js 22 veya üzeri gerekir. Bu tag'in kaynak arşivini açtıktan veya depoyu
bu tag'de klonladıktan sonra `npm ci --ignore-scripts`, `npm run build` ve
`npm run check` çalıştırın. MCP bağlantısı için kaynak arşivindeki `README.md`
ve `examples/mcp-config.json` dosyalarını kullanın. Hazır çalıştırılabilir
ikili veya npm paketi bu release kapsamında yayımlanmaz.

## Doğrulama ve sınırlar

Sürüm hazırlama otomasyonu Ubuntu 24.04 üzerinde Node 22/24 ve macOS üzerinde
Node 24 ile çevrimdışı kontrolleri, ayrıca üretim bağımlılığı denetimini çalıştırır.
Sentetik testler gerçek fiyat, stok, kampanya, uzak API veya masaüstü istemcisinin
manuel kabul doğrulaması değildir. Bu sürüm hazırlığında canlı API testi yapılmaz.

Varsayılan `MARKET_FIYATI_MODE=offline`; deneysel uçlar kapalıdır. Canlı erişim,
API kullanım izinleri ve operatör kararı gerektirir. Pazar/şube kapsamı eksiksizlik
garantisi vermez; market listesi deneyseldir ve HTTP 500 dönebilir. Ayrıntılar
kaynak arşivindeki `docs/verification.md` ve `docs/live-testing.md` belgelerindedir.

Sunucu resmî Market Fiyatı ürünü değildir. Yazılım MIT lisanslıdır; bu lisans
üçüncü taraf verilere veya servislere erişim izni sağlamaz.
