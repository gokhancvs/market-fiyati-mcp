# v1.0.0

Kaynak arşivini açın ve Node.js 22+ ile kurun:

```sh
npm ci --ignore-scripts
npm run build
npm run check
```

MCP bağlantısı için arşivdeki `README.md` ve `examples/mcp-config.json` dosyalarına bakın. Bu ilk sürümde
hazır derlenmiş dosya veya npm paketi yayımlanmaz; `private: true` ayarı paketin npm'de yayımlanmasını engeller.

## İçerik

- Ürün arama, şube fiyatları, fiyat geçmişi ve sepet karşılaştırması için **15 tool, 3 resource, 3 prompt**.
- Her çağrıda açıkça verilen konum ve şubeler, API facet filtreleri ve sınırlı sayfalama.
- TRY/kuruş bazında hesaplama; eksik sepette `total=null`.
- Upstream uyarıları, istek ölçümleri ve şube kapsamı; iptal, timeout, bütçe ve kaynak sınırları.
- Ağ erişimi engellenmiş sentetik testler ve istemciden bağımsız bir kabul kiti.

## Doğrulama sınırı

Sürüm hazırlık otomasyonu Ubuntu 24.04 üzerinde Node 22/24, macOS üzerinde Node 24 ve üretim bağımlılığı
denetimini çalıştırır. Sentetik testlerin geçmesi gerçek fiyat, stok, kampanya, uzak API veya masaüstünde
elle yapılmış kabul testi için kanıt değildir. Bu sürüm hazırlanırken live API testi yapılmadı.

Varsayılan mod `offline`'dır ve deneysel endpoint'ler kapalıdır. Live erişim, operatörün kararını ve API
iznini gerektirir. Zincir ve şube kapsamının eksiksiz olduğu garanti edilmez; deneysel market listesi HTTP 500
dönebilir. [Doğrulama](../verification.md) · [Live test](../live-testing.md).

Bu, Market Fiyatı için bağımsız ve resmî olmayan bir yazılımdır. MIT lisansı üçüncü taraf verilere veya
servislere erişim izni vermez.
