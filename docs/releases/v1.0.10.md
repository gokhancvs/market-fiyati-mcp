# v1.0.10

MCP SDK 1.32.1'e yükseltildi ve bağımlılık denetimindeki `proxy-addr` güvenlik bildirimi kapandı.
Türkçe belgeler tek terim sözlüğüyle yeniden düzenlendi.

## Değişenler

- **Güvenlik:** `@modelcontextprotocol/sdk` 1.29.0'dan 1.32.1'e yükseltildi. SDK'nın `express` bağımlılığı
  üzerinden gelen `proxy-addr` 2.0.8'e güncellendi
  ([GHSA-jqcg-44mw-7w3h](https://github.com/advisories/GHSA-jqcg-44mw-7w3h)). Sunucu yalnız stdio kullanır
  ve express'i yüklemez.
- **Argümansız çağrı:** Zorunlu alanı olmayan tool'lar (`market_status` gibi) `arguments` gönderilmeden de
  çağrılabilir. SDK giriş hatası metinleri yeni biçimde gelir; `Input validation error` öneki aynı kalır.
- **Büyük yanıtlar:** MCP SDK 1.30 ve sonrasını kullanan stdio istemcileri varsayılan olarak 10 MiB'den büyük
  bir mesajı okumaz ve bağlantıyı kapatır. Sorgu kapsamını (`size`, şube sayısı) küçük tutun.
- **Belgeler:** Terimler, kesme işaretleri ve anlaşılmayan cümleler düzeltildi. `api.md` içindeki konum
  başlığı "Konum ve şube bağlamı" oldu. Sürüm notlarındaki linkler kendi tag'lerine sabitlendi.

## Geçiş

Mevcut kurulumlar değişiklik gerektirmez. İstemci yapılandırmasındaki sürüm pinini
`market-fiyati-mcp@1.0.10` yapıp sunucuyu yeniden başlatın.

## Doğrulama

Offline kontroller, fake fetch testleri ve bağımsız kurulum testi SDK yükseltmesini, argümansız çağrıyı ve
paket içeriğini sınar. Bağımlılık denetimi açık bildirmez. Yeni live API veya masaüstü istemci kabulü iddia
edilmez.
