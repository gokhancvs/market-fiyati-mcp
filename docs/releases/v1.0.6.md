# v1.0.6

## Değişiklikler

- `MARKET_FIYATI_LATITUDE`, `MARKET_FIYATI_LONGITUDE` ve `MARKET_FIYATI_DISTANCE` ile konumu bir kez
  MCP env yapılandırmasına yazabilirsiniz. Üçü birlikte ayarlanır veya tamamen kaldırılır.
- Enlem -90..90, boylam -180..180, distance 0’dan büyük ve en fazla 50 km olmalıdır.
  Env değerleri sayısal string, ondalık ayırıcı noktadır. Geçersiz veya eksik kurulum başlangıçta reddedilir.
- Çağrıdaki tam koordinat çifti env çiftinin, çağrıdaki distance env yarıçapının önüne geçer. Tek bir
  koordinat gönderilemez. Çağrılar ayarları değiştirmez; sonraki çağrı yine env değerlerini kullanır.
- `market_status` yalnız `locationDefaults.configured` bilgisini paylaşır; ayarlı koordinatları
  yayımlamaz. Şubeler (`depots`) ürün çağrılarında açıkça sağlanmaya devam eder.

## 1.0.5’ten geçiş

**Örtük 1 km yarıçapı kaldırıldı.** Env kullanmıyorsanız konum gerektiren çağrılara `latitude`,
`longitude` ve `distance` değerlerini birlikte ekleyin. Env kullanıyorsanız üç değişkeni kurun;
AI bunları her sorguda tekrar sormadan kullanabilir. Ters geocode upstream sözleşmesi gereği yalnız
koordinat alır. Konum gerektirmeyen araçlara yeni zorunlu alan eklenmez.

Paket yayımlandıktan sonra istemci ayarındaki sürüm pinini `market-fiyati-mcp@1.0.6` yapıp
sunucuyu yeniden başlatın. Tam yapılandırma [README’de](../../README.md), gerçek fiyatlarla
deneme adımları [canlı test rehberinde](../live-testing.md) bulunur.

## Doğrulama kapsamı

Env doğrulama, çağrı önceliği, eksik girdilerin HTTP öncesi reddi, tüm konum araçlarının SDK
payload’ları ve offline/deneysel erişim kilitleri sentetik testlerle sınanır. Bağımsız tüketici kontrolü
üretim bağımlılıklarıyla kurulan npm binary’sini sınar. Bunlar canlı API veya masaüstü istemci kabulü
değildir. Ayrıntılar: [Doğrulama](../verification.md).
