# Güvenlik bildirimleri

Güvenlik açıklarını [GitHub özel güvenlik bildirimi](https://github.com/gokhancvs/market-fiyati-mcp/security/advisories/new)
üzerinden iletin. Açık issue veya pull request içine istismar ayrıntısı, token, header,
tam adres, kişisel koordinat veya ham API yanıtı koymayın.

Destek kapsamı en güncel kararlı sürümdür. Bildirimde etkilenen sürümü, beklenen/gözlenen
davranışı ve mümkünse sentetik verili, ağ erişimi gerektirmeyen yeniden üretme adımlarını yazın.
Düzeltmenin kapsamı ve yayın zamanı inceleme sonucunda belirlenir; sabit yanıt süresi taahhüdü yoktur.

Bu projenin bildirimi üçüncü taraf servisleri test etme veya onlara erişme izni vermez.
Market Fiyatı API'sinde izinsiz tarama, yük veya istismar testi yapmayın.
